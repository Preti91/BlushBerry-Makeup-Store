# 💄 BlushBerry Makeup Store

### A Simple Advanced Java E-Commerce Web Project

**BlushBerry Makeup Store** is a beginner-friendly web-based makeup shopping project developed as part of learning **Advanced Java / Java Web Development**.

The project demonstrates how Java web technologies can be used to build a simple online makeup store where users can browse beauty products and interact with the website.

---

## 🌸 Project Overview

BlushBerry is designed as a basic online makeup store with a beauty-focused interface.

The main purpose of this project is to understand the fundamentals of **Java web application development**, including project structure, web pages, server-side Java concepts, and database connectivity.

This project was created as a **learning project** to strengthen practical knowledge of Advanced Java.

## 💻 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/Preti91/BlushBerry-Makeup-Store.git
```

### 2. Open the project

Open **Eclipse IDE**.

Select:

```text
File → Import → Existing Projects into Workspace
```

Select the `BLUSH1` folder.

### 3. Configure Apache Tomcat

Add the project to your configured Apache Tomcat server.

Then:

```text
Right Click Project
        ↓
Run As
        ↓
Run on Server
        ↓
Select Apache Tomcat
```

### 4. Open in browser

After starting the server, open the application using the URL provided by your Tomcat configuration, for example:

```text
http://localhost:8080/BLUSH1/
```
